# Python File Sorter

A Python automation script that organizes files into folders based on their extensions.

## Supported File Types
- Images (.png, .jpg, .jpeg, .webp)
- PDFs (.pdf)
- Excel Files (.xlsx)
- CSV Files (.csv)
- Word Documents (.doc, .docx)
- Executables (.exe)
- MSI Installers (.msi)
- ZIP Archives (.zip)
- RAR/7Z Archives (.rar, .7z)

## Technologies Used
- Python
- os
- shutil

## How to Run

1. Update the path variable.
2. Run:

python sorting.py
